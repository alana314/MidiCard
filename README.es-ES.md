

# MidiCard  
  
MidiCard está disponible para su compra en: [https://makerproducts.art/product/midicard-plus-25-key-small-midi-piano-keyboard-controller/](https://makerproducts.art/product/midicard-plus-25-key-small-midi-piano-keyboard-controller/)
  
Este es el código de Arduino para MidiCard, un mini teclado MIDI USB C en PCB impulsado por un Seeed Studio Xiao SAMD21 con 25 botones multiplexados: los pines 0-4 son de entrada y los pines 6-10 son de salida. La placa tiene 18 teclas, y botones de función para OCT-, OCT+, SUS, MOD, P, MF y FF. 
  
https://wiki.seeedstudio.com/Seeeduino-XIAO/

La rama plusv1.0 contiene el código para el MidiCard Plus de 25 teclas, el cual utiliza un chip SAMD21G18A sin placa de desarrollo.
